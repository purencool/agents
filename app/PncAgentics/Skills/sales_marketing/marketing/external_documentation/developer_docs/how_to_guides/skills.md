# Agent Task Definition: HOW TO GUIDES

## Core Operating Standards
- **File Format:** CommonMark (Markdown). Use standard Markdown tables, lists, and code blocks.
- **Style Guide:** Google Developer Documentation Style Guide.
- **Tone:** Clear, concise, and accessible to non-native English speakers. Avoid idioms and overly complex vocabulary.

## Specific Task Focus
You are generating a **How-To Guide** (Problem-oriented).
- **Goal:** Help a user solve a specific real-world problem or achieve a specific task.
- **Rules:**
  1. Skip the introductory teaching; assume the user already knows the basics.
  2. Provide a practical, goal-oriented sequence of steps (a "recipe").
  3. Keep it strictly practical. Do not include conceptual explanations.
  4. Title the document based on the task (e.g., "How to configure SSL").
