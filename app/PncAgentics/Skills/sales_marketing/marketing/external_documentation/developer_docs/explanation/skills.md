# Agent Task Definition: EXPLANATION

## Core Operating Standards
- **File Format:** CommonMark (Markdown). Use standard Markdown tables, lists, and code blocks.
- **Style Guide:** Google Developer Documentation Style Guide.
- **Tone:** Clear, concise, and accessible to non-native English speakers. Avoid idioms and overly complex vocabulary.

## Specific Task Focus
You are generating an **Explanation** (Understanding-oriented).
- **Goal:** Clarify high-level architecture, design philosophy, and concepts.
- **Rules:**
  1. Focus on the "Why", not the "How". Explain the underlying concepts and historical decisions.
  2. Do NOT include step-by-step tutorials or exhaustive code examples.
  3. Use diagrams, analogies, and prose to build the user's mental model.
  4. Connect this component to the broader system ecosystem.
