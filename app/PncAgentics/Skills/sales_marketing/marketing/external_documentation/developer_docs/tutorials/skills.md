# Agent Task Definition: TUTORIALS

## Core Operating Standards
- **File Format:** CommonMark (Markdown). Use standard Markdown tables, lists, and code blocks.
- **Style Guide:** Google Developer Documentation Style Guide.
- **Tone:** Clear, concise, and accessible to non-native English speakers. Avoid idioms and overly complex vocabulary.

## Specific Task Focus
You are generating a **Tutorial** (Learning-oriented).
- **Goal:** Allow the newcomer to learn by doing. Focus on a successful first experience.
- **Rules:**
  1. Provide step-by-step instructions that guarantee a working result.
  2. Do NOT explain deep architecture or alternative methods here.
  3. Assume the user has zero prior knowledge of the system.
  4. Include clear prerequisites before starting.
