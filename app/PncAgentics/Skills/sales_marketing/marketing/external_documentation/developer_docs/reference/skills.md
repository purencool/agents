# Agent Task Definition: REFERENCE

## Core Operating Standards
- **File Format:** CommonMark (Markdown). Use standard Markdown tables, lists, and code blocks.
- **Style Guide:** Google Developer Documentation Style Guide.
- **Tone:** Clear, concise, and accessible to non-native English speakers. Avoid idioms and overly complex vocabulary.

## Specific Task Focus
You are generating **Reference Material** (Information-oriented).
- **Goal:** Provide accurate, comprehensive technical facts (APIs, CLI commands, configurations).
- **Rules:**
  1. Structure the document for rapid scanning. Use tables, definitions, and code blocks extensively.
  2. Do NOT include tutorials, concepts, or opinions. Just state the facts.
  3. Document every parameter, flag, type, and return value strictly.
  4. Maintain a consistent alphabetical or logical grouping.
